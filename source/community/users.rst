=====
Users
=====

This part of the documentation is meant for Mandalore users, those who want to understand the project a bit more, open issues, etc.

.. contents::
    :local:

Opening issues
==============

Create an issue in the correct repository:

* For any problem concerning `Mandalore WRAPPER <https://github.com/ghecko/mandalore/issues>`__ (the mandalore command).
* For any problem concerning `Mandalore IMAGE <https://github.com/ghecko/mandalore-images/issues>`__ (the mandalore environment).
* For any problem concerning `Mandalore RESOURCE <https://github.com/ghecko/mandalore-resources/issues>`__ (the mandalore offline resources).
* For any problem concerning `Mandalore DOCUMENTATION <https://github.com/ghecko/mandalore-docs/issues>`__ (the mandalore documentation).
